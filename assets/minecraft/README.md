# Minecraft assets

Textures and sounds from Minecraft Java Edition 1.21.4.
Textures mirrored from https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4

Download URLs and SHA-256 checksums are in `sources.json` and `sounds/sources.json`.
The app loads the bundled PNG and WAV files locally.

Minecraft assets belong to Mojang / Microsoft. This is an unofficial fan project.
