# Minecraft textures

Unmodified PNG textures from Minecraft Java Edition 1.21.4, mirrored by
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4

Food items, UI icons, clock, armor, and duel symbols use the original textures.
TNT uses textures/block/tnt_side.png.
Exact download URLs and SHA-256 checksums are recorded in sources.json.
Images are loaded locally and scaled by integer nearest-neighbor zoom in Tk.
No internet connection is needed while playing.

Minecraft textures belong to Mojang / Microsoft. This is an unofficial fan project.
